Every hardware panel below shows its real captured seed (firmware instrumentation added specifically for this), not an approximation — replaying that exact seed through the Python golden reference AND the real per-layer-DDR3-streaming RTL simulation both reproduce the board's own trajectory almost everywhere they've been checked, diverging only at rare, razor-thin near-ties (~0.1% logit margins) that no simulation reproduces. Not an RTL bug, not a firmware bug, not a checkpoint issue — see model/SCALE-UP-LOG.md for the full chain. Separately: not an apples-to-apples weight comparison — the board runs the QAT/INT4 checkpoint; the plain GPT.generate() class can't load that quantized state dict, so the software side runs the pre-QAT FP checkpoint (ckpt_stepC_d128_v16384.pt) at the board's calibrated temperature instead, the closest practical proxy, not a bit-exact one.
