Not an apples-to-apples weight comparison. The board runs the QAT/INT4-quantized checkpoint; the plain GPT.generate() class can't load that quantized state dict, so the software side here runs the pre-QAT FP checkpoint (ckpt_stepC_d128_v16384.pt) at the board's calibrated temperature instead — the closest practical proxy, not a bit-exact one. Real hardware also has no controllable seed: each draw is the on-chip free-running counter, not a reproducible value — "draw 1-5" below labels independent samples, not matched randomness across columns.
